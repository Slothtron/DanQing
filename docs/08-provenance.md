### 1.1 采集踩坑（复现时会遇到）

站点切换色系后，色卡的 `style` 属性匹配不到新色值——色值是通过 CSS 类或变量注入的。
必须走 `getComputedStyle(card).backgroundColor` 再解析 `rgb()`。

```js
// 正确
const cards = [...document.querySelectorAll('.color-card')];
cards.map(c => getComputedStyle(c).backgroundColor)
     .map(rgb => '#' + rgb.match(/\d+/g).slice(0,3)
                          .map(x => (+x).toString(16).padStart(2,'0')).join('').toUpperCase());
// 错误：c.getAttribute('style').match(/#[0-9A-F]{6}/) —— 切换色系后取不到
```

同时，站点用 `<button>` 承载色系标签，切换需 `click()` 后**等待渲染**再提取（约 2s）。

## 2. 选色依据：五方正色 + 间色

传统中国色彩不是一个色相环，而是一套**等级化、有出处的命名体系**，其中最基本的结构是「正色 / 间色」：

> 《礼记·玉藻》：「衣正色，裳间色。」
> 正色：青、赤、黄、白、黑 —— 对应五方五行，是「独立而不相杂」的颜色；
> 间色：绀、红、缥、紫、流黄等 —— 由正色相杂而成，属于次级色。

这个结构与设计系统的需求高度吻合：

| 传统观念 | 设计系统对应 |
|---|---|
| 正色数目有限、含义明确 | 功能语义色（状态色）应该少而固定 |
| 间色由正色相杂、情绪性强 | 品牌色、强调色、数据可视化色可以更丰富 |
| 「随类赋彩」——颜色跟着物象类别走 | 语义角色驱动用色，而非「这个好看就用这个」 |
| 讲究留白与克制 | 强调色面积建议 < 10% |

丹青因此把 11 个色族分成两类：**保留族**（承担状态语义）与**品牌候选族**（承担主色）。

## 3. 十一个锚点：候选与取舍

每个色族从色库中「选拔」出一个锚点。选拔标准有三条：

1. **色相可用** —— 能覆盖一个明确的语义角色，且与已选锚点区分得开；
2. **明度合适** —— 在 OKLCh 中落位后，能同时支撑浅色与深色两套语义；
3. **有出处、有说法** —— 是真实的传统色名，不是现代色卡的生造名。

### 3.5 `jiang` 绛 → 朱樱 `#8F1D22`（保留族 → danger）

与 `zhu` 同色相、不同明度。这是刻意的：

- 用户余光扫过时，**深红 = 危险**，**正红 = 印记与强调**；
- 两者并置（如「删除」按钮与「标记」按钮同屏）时仍可分辨；
- 避免「危险色用橙红、强调色用正红」这种靠细微色相差区分的做法。

## 4. 最近邻命名：让色阶保留中文语感

生成 11 级色阶后，每一级都会在 384 条传统色中做 OKLab 欧氏距离最近邻搜索，记录：

- `name` / `pinyin` —— 最近传统色名
- `nearestHex` —— 该传统色的原始色值
- `nearestGroup` —— 所属色系（赤/黄/青/蓝/紫/白/玄/褐）

例（`qing` 族）：

| 级 | 生成色 | 最近传统色 | 原值 | 距离感知 |
|---|---|---|---|---|
| 50 | `#F2F7FF` | 山矾 | `#F5F3F2` | 极淡蓝白 |
| 100 | `#D1E2FF` | 月白 | `#D4E5EF` | 淡青白 |
| 200 | `#B1CAF6` | 碧落 | `#AED0EE` | 浅天蓝 |
| 300 | `#92B2EB` | 窃蓝 | `#88ABDA` | 浅蓝 |
| 400 | `#759BDC` | 监德 | `#6F94CD` | 中蓝 |
| 500 | `#5A83CC` | 紫苑 | `#757CBB` | **已偏紫** |
| 600 | `#416CBA` | 青冥 | `#3271AE` | 正蓝 |
| 700 ◀ | `#2E59A7` | **群青** | `#2E59A7` | 锚点，距离 0 |
| 800 | `#1A4188` | 绀宇 | `#003D74` | 深蓝 |
| 900 | `#092964` | 帝释青 | `#003460` | 深靛 |
| 950 | `#011541` | 獭见 | `#151D29` | 近墨 |

这张表在设计评审里非常有用：当有人说「这里的蓝不够纯」时，可以指出 500 级在感知上已经接近紫苑（紫蓝），
想要更纯的蓝应该往 600–700 走。**这是把「感觉」变成可讨论的数字。**

反查结果不参与令牌 id 生成（避免一色多名导致 id 漂移），只用于报告、文档与 Figma 描述。
